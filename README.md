# 💸 NearCash — Smart Nearby Cash Exchange App

NearCash is a modern **Flutter mobile application** that helps nearby users exchange cash denominations quickly and securely within a **1 KM radius**.

Need ₹500 in smaller notes? Need change for cash payments? NearCash connects nearby users instantly for real-world cash exchange.

Built as a demo product using **Flutter + Dart**, focused on clean UI, smooth user experience, and location-based interactions.

## 🚀 Project Highlights

✨ Nearby cash exchange within 1 KM  
✨ Clean and modern mobile UI  
✨ Real-time request acceptance flow

### 💵 Raise Cash Exchange Request

Users can create requests like:

📌 Need ₹500 in ₹100 notes  
📌 Need ₹2000 broken into smaller notes  
📌 Need exact cash change  

Users can specify:

✅ Amount  
✅ Required denomination  
✅ Current location  

---

### 📍 Nearby Request Discovery

The app shows nearby requests within:

🎯 **1 KM Radius**

Users can:

✔ Browse nearby requests  
✔ View request details  
✔ Connect instantly

### 🤝 Accept Request

When a user accepts a request:

✨ Success animation appears  
✨ Request gets locked  
✨ Chat opens automatically
